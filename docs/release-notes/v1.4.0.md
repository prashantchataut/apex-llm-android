### Apex LLM v1.4.0

**Native in-app APK updater.** "Update Now" no longer opens Chrome or GitHub. The APK streams inside the app with live progress, then the system installer opens through FileProvider.

**On-Device Local AI Runner.** The first onboarding screen and the showcase now describe Apex as a private, on-device runner for open-weight models.

**Local model hub.** Added Qwen3 0.6B / 1.7B / 4B, Gemma 3 4B, LiquidAI LFM2 350M / 1.2B, SmolLM2 360M and Dolphin 3.0 3B, all with the redirect-safe downloader that tolerates a missing Content-Length.

**Built-in PDF reader.** Open a PDF, page through it, zoom, jump to a page, search the text, then tap "Summarize PDF" or "Ask AI about this PDF". pdf.js is bundled and runs offline.

**Math.** KaTeX is bundled locally. `$inline$` and `$$block$$` LaTeX render in chat, and block equations have a "Copy LaTeX" button.

**System instructions.** Settings has preset chips on top of the custom-instructions box. The text is sent as the system message on every local and cloud chat.

**/admin keyless models.** Per-model on/off switch, inline rename, per-model "Ping" and "Test all models live" (real chat completions, WORKING / FAILED with latency). Publishing writes `mesh.json`, so disabled models leave the app picker and the failover chain and renamed models show their new names.

**Honest limits.** Only models that answer without an API key are listed. At the time of this release 14 pass a live "Reply with OK" probe (OVHcloud, LLM7, Pollinations). GPT-4.1, Claude and Gemini need a key and are not offered.
