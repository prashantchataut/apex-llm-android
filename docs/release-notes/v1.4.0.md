### Apex LLM v1.4.0 - On-Device Local AI Runner and Private Pocket Intelligence Studio

Apex runs open-weight models on your phone, keeps your chats on the device, and adds cloud models only when you ask for them.

**Native in-app updater.** "Update Now" never opens Chrome or GitHub. The APK downloads inside the app with live progress (`Downloading v1.4.0... 42%`), then Android's package installer opens through FileProvider.

**Local Model Hub.** 28 downloadable GGUF models, including Qwen3 0.6B / 1.7B / 4B, Gemma 3 1B / 4B, LiquidAI LFM2 350M / 1.2B, DeepSeek-R1-Distill-Qwen 1.5B, Phi-4 mini, Llama 3.2 1B / 3B, SmolLM2, Dolphin 3.0 and abliterated Qwen / Llama builds. The downloader follows redirects and keeps going when a server omits `Content-Length`. Every download link was checked against Hugging Face for this release.

**Apex Mesh catalog.** 55 gateways and 471 models imported from the public provider list, 159 of them verified with a real chat completion at import time. Paid routes and anything that needs a secret are not included. Failover chains the fastest verified gateways.

**/admin.** Passphrase-only sign-in. Searchable catalog with All / Working / Enabled / Failed tabs, on/off switches, inline rename and category, Test Live per model and batch verify with WORKING (ms) / OFFLINE badges, plus the inline access-key editor.

**Image Studio.** Enhance prompt, 1:1 / 9:16 / 16:9 / 4:5, style presets, Flux Schnell / Pro / Anime / 3D with automatic fallback, shimmer loading, and a saved local gallery.

**Built-in PDF reader.** Page through, zoom, jump to a page, search, then Summarize PDF or Ask AI about this PDF. pdf.js is bundled and runs offline.

**Math.** KaTeX is bundled. `$inline$` and `$$block$$` LaTeX render in chat, and block equations have a Copy LaTeX button.

**System instructions.** Presets plus a custom box in Settings, sent as the system message on every local and cloud chat.

**GitHub.** One tap connects to @prashantchataut's public repositories.

**Design.** Obsidian `#09090B` surfaces, border-beam cards, segmented pills, a spring slide-over drawer, a status-bar-safe header, and no emoji.
