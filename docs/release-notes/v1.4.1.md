# Apex LLM v1.4.1: layout fixes and admin sign-in

- **No more overlapping controls** on 360 to 412 px phones: header model pill truncates instead of colliding with the menu and new-chat buttons, the Settings theme control fits its card, and the chat scroll area keeps 140 px of clearance above the composer.
- **One z-index scale**: header and composer 20, popovers 40, side drawer 50, modals / PDF reader / studio 60, toasts 70. Nothing bleeds through an open drawer or modal.
- **/admin sign-in**: passphrase-only. `apex-admin-2025` and the master key `APEX-PRO-2025` both unlock the console (trimmed, case-insensitive).
- Model list requests to LLM7 no longer send an Authorization header, which the browser CORS preflight rejected.
- Catalog re-probed: refreshed Working / Failed status for every imported model.
- Native in-app updater, PDF reader, offline LaTeX, Image Studio and 1-tap Connect @prashantchataut are unchanged from v1.4.0.
