# Apex LLM v1.7.0

## Fixed
- **Cloud replies no longer cut off mid-output.** OpenAI-format requests now send `max_tokens: 8192` (they sent none, so relays applied their own small caps) and the chat layer no longer caps cloud turns at 900 tokens.
- **Reasoning stays out of the answer.** `delta.reasoning_content`, `delta.reasoning`, `<think>` blocks and plain-text planning printed before a code block are routed into the collapsible Thinking Trace. Raw `<!doctype html>` output is fenced and previewed.
- **No prompt leak.** Slide-deck and web-app instructions moved from the visible message into the `system` role.

## New
- **Model Switcher**: four tabs (Auto & Free, Apex API, On-Device, All), one line per model.
- **Free Cloud Models (Instant)**: Apex Auto Free, GPT-4.1 Mini, Gemini 2.5 Flash, DeepSeek V3, Qwen 3 Coder, Llama 3.3 70B. No key, no download. Only routes that passed a live completion probe are listed.
- **Apex Auto Pro** is the first option in Apex API.
- **Real `.pptx` export** (`pptxgenjs`) with a one-tap Download card in the chat bubble.
- **Virtual Localhost** live preview: Blob-URL sandbox, address bar, Live Reload, Phone/Desktop, Source, Fullscreen, `.html` and `.pptx` downloads, and auto-closing of truncated HTML.
- **Voice**: instant streaming speech input, on-device speech model of your choice (Moonshine Tiny, about 28 MB, or Whisper tiny, about 40 MB; both run offline after a one-time download), Read Aloud with play/pause/stop, Auto-Speak, voice and speed in Settings.
- **GitHub**: connect by username (no token) or by personal token; browse file trees, attach files or READMEs to chat, create Gists.
- Four starter cards and a minimal pill bar replace the prompt-template list.

## Honest limits
- Flagships with no working route in the bundled catalog (Claude 3.7 Sonnet, GPT-4.5, Grok 3, and o3 / o4-mini / Gemini 2.5 Pro whose routes failed the probe) are shown as "No live route", not faked. See `web-showcase/src/data/flagship-probe.json`.
- Neural read-aloud goes through a shared relay that can rate-limit; on any failure Apex falls back to the device voice instantly.
- Parakeet-CTC is not bundled: no browser-runnable ONNX build small enough for a phone download exists, so Moonshine Tiny and Whisper tiny are the on-device options.
- The model count shown on the All tab is the real number of routable models, not a padded figure.
