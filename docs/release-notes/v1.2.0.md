## Apex LLM v1.2.0

**Install note:** this release is signed with a new, **permanent** release key (stored as repo secrets). Uninstall any earlier build
(v0.x – v1.1.0, which were signed with throw-away per-run keys) **once**; every future release will update in place.

### Android 15 / Nothing OS install hardening
- `targetSdk 34`, `compileSdk 36`, `minSdk 26`; arm64-v8a only (no x86 / armeabi stubs; `abiFilters` + CI check).
- Native library linked with `-z max-page-size=16384` (16 KB pages) and stored compressed (`useLegacyPackaging`).
- Unused `FOREGROUND_SERVICE` permission removed; every manifest component declares `android:exported`.
- CI order: unsigned build → `zipalign -p 4` → `apksigner` v1+v2+v3 → `scripts/verify-apk.sh` gate (signatures, manifest, ABI, ELF alignment).
- A CI run now builds and verifies an APK on **every push**.

### Provider Mesh
- Live-discovered models from OVHcloud (anonymous), LLM7.io (free tier) and Pollinations, grouped by category in the model switcher.
- Instant failover on 429 / 5xx / timeout.
- `/admin` panel: provider health + latency, one-tap model sync, add your own open endpoint without rebuilding.
