# Apex LLM v1.5.0

On-Device Local AI Runner and Private Pocket Intelligence Studio.

## What is new
- **Frontier Flagships tier.** The catalog now opens with Claude, GPT, o-series, Gemini, Grok, DeepSeek, Qwen, Llama and Mistral flagship names, each mapped onto the live routes that actually answer today, with multi-provider failover. A flagship with no live route is shown as such instead of being faked.
- **Anthropic Messages adapter.** Relays that speak the Anthropic wire format (`/v1/messages`) are now first-class mesh providers, next to OpenAI-compatible gateways.
- **Larger catalog.** 1,198 models from 65 gateways imported from the reference catalog and live discovery, each with a real-completion probe result where it could be probed.
- **Command-style Model Switcher.** Search, pinned models, Frontier Flagships, provider pills (On-Device Local, Anthropic, OpenAI, Google, xAI Grok, DeepSeek, Qwen, Llama 4, Uncensored), capability tags and live latency badges.
- **Compare 2 Models.** One prompt, two models streaming side by side (swipeable tabs on phones) with first-token latency and tokens per second.
- **/admin.** Passphrase-only sign-in (`apex-admin-2025` or `APEX-PRO-2025`), category tabs, per-family ON/OFF, inline rename and tier edit, Test Live, Batch Verify Frontier Models, Save and Publish.
- **Layout.** Message list bottom padding raised to `pb-36`; header actions share one flex group so nothing collides on 360 to 412 px screens.

## Install
Download `Apex-LLM-v1.5.0-arm64-release.apk` (arm64-v8a, Android 8 and up). Existing installs update in place from Settings.
