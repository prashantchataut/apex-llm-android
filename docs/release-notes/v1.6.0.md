# Apex LLM v1.6.0: Local AI Runner and Private Pocket Studio

**Install:** download `Apex-LLM-v1.6.0-arm64-release.apk` below (arm64, signed v1+v2+v3, zipaligned).

## What's new
- **Connect your own GitHub.** No account, token or fallback profile ships with the app. Use GitHub device login, a personal token (stored only in this device's `localStorage`), or a public username. One tap to disconnect.
- **Apex API keys are verified live.** Every start and every request re-reads `apex-vault.json` (`no-store`); the stored key fingerprint must still match an active key. Replace the key in /admin and the old key stops working.
- **Keyboard-safe dialogs.** The key dialog sits in the upper half of the screen and tracks the visual viewport, so the field, the message and the Unlock button stay visible above the Android keyboard.
- **New Home and onboarding** built around the Apex mark: an engine status pill and four creation cards (Presentation, PDF, Interactive page, Studio artwork).
- **Fast Direct Mode.** Local models get a minimal prompt and stream immediately. "Enable Agent Harness for Local Models" is off by default. Haptic Feedback: Off (default), Subtle, Normal.
- **Expandable ThinkingTrace, SelectionActions rewrite bar and LivePreviewViewer** (phone, tablet, code, slide decks, export to PDF).
- Prompt templates, tok/s and time-to-first-token pill, stop button, chat search and pinning, in-app PDF viewer, offline KaTeX.
- /admin: add a custom provider, reorder failover, toggle, rename and ping.
