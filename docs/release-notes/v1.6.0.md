# Apex v1.6.0 (source)

- GitHub: every user connects their own account (device login, personal token in local storage, or a public username). No bundled account or token.
- Apex API: the stored key fingerprint is re-verified against the live vault on start and before each request. Replacing the key in /admin locks the old one. No offline grace.
- /admin: passphrase-only (no alias). Add a custom provider (name, base URL, model ID, category, optional header, system prompt, timeout), reorder failover, toggle, rename, ping.
- Dialogs: top-aligned, `interactive-widget=resizes-content`, visualViewport tracking, scroll-into-view on focus.
- Local engine: Fast Direct Mode by default. "Enable Agent Harness for Local Models" is off by default. Haptic Feedback: Off (default), Subtle, Normal.
- ThinkingTrace, SelectionActionsBar and LivePreviewViewer.
- Prompt templates, tok/s and TTFT pill.

Build status: the APK for this version has not been compiled yet.
